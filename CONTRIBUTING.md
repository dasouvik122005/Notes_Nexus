# Contributing to Notes Nexus

First off, thank you for considering contributing to Notes Nexus! It's people like you that make Notes Nexus such a great tool for the JIS University CSE community.

## How Can I Contribute?

### 1. Contributing Notes or Previous Year Questions (PYQs)
If you are a student or faculty member and you have study materials, notes, or previous year question papers that are missing from our platform, you can contribute them directly!

- **Submit via Google Form**: The easiest way to share your notes is through our dedicated [Feedback & Contribution Form](https://forms.gle/WfbtFjHj3pS9RyQg9).
- **Accepted Formats**: PDF, high-quality images, and Google Drive links.

### 2. Contributing to the Codebase
Notes Nexus is open-source and built with Next.js, React, and Vanilla CSS using a Neo-Brutalist design language. We welcome pull requests!

#### Local Development Setup
1. Fork the repo and clone it locally.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server at `http://localhost:3000`.

#### Pull Request Process
1. Create a new branch for your feature or bugfix (`git checkout -b feature/AmazingFeature`).
2. Make your changes. Please ensure you adhere to the existing Neo-Brutalist CSS variables and design tokens in `globals.css`.
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
4. Push to the branch (`git push origin feature/AmazingFeature`).
5. Open a Pull Request. Provide a clear description of the changes.

## Style Guide
- **CSS**: We use pure Vanilla CSS (no Tailwind) to maintain absolute control over the Neo-Brutalist shadows and borders.
- **Icons**: We use `lucide-react` for standard UI icons and `react-icons/fa` for brand logos.

Thank you for helping us make studying easier for everyone!
