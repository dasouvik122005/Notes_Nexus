# Security Policy

## Supported Versions

Currently, the following versions of Notes Nexus are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover any security related issues, please email the Notes Nexus team directly rather than opening an issue on GitHub. 

We take all security vulnerabilities seriously and will work with you to resolve the issue promptly. We will try to reply to your email within 48 hours.

When reporting a vulnerability, please include:
* A detailed description of the vulnerability.
* Steps to reproduce the issue.
* Any potential impact or risk you have identified.

Thank you for helping keep Notes Nexus safe and secure!
